# javascript-lotto-precourse

사용자에게 받은 금액 만큼 로또 번호를 생성하여 로또 번호와 비교한 뒤 얼만큼의 수익률을 내었는지 확인하는 프로그램 입니다.

1. 사용자에게 금액을 입력받는다.
2. 입력 받은 금액 만큼 무작위 로또를 출력한다.
3. 당첨 로또 번호를 입력받는다.
4. 보너스 번호를 입력받는다.
5. 사용자의 로또 번호와 당첨 로또 번호를 비교해서 수익금을 사용자에게 보여준다.
6. 수익률을 계산한 뒤 출력한다.

## 예외 처리 상황

### 구입금액

1. 숫자가 아닌 경우 : {kimm}
2. 1,000원으로 나누어 떨어지지 않는 경우 : {1009}
3. 숫자와 문자가 같이 있을 경우 : {1000j}
4. 천원보다 작을경우 : {900}
5. 숫자 앞에 0이 있을 경우 : {01000}
6. 공백이 포함될 경우 : {1 000}

### 당첨번호

1. 중복되는 숫자가 있는 경우: {1,1,1,1,2,4}
2. 1~45의 정수가 아닌 경우 가 아닌경우 : {2123,1,2,3,4,5}
3. , 이외의 문자가 있을 경우 : {1,2.5,3,-4,5,&}
4. 처음과 마지막이 , 시작하거나 끝나는 경우 : {,1,2,3,4,5,}
5. 숫자 사이에 공백이 있을 경우 : {1 ,2,3,4,5,6}
6. 당첨번호가 6자리 아닌 경우 {1,2} or {1,2,3,4,5,6,7}

### 보너스 번호

1. 1~45의 숫자가 아닌 경우 : {63}
2. 문자가 있을 경우 : {13a}
3. 공백이 포함된 경우 :{ 4}
